# Audio Assets — Deepak Express

Place royalty-free audio files here. The sound system will gracefully
skip any missing files (no errors thrown in production).

## Required files

| File | Description | Loop | Suggested search |
|---|---|---|---|
| `ambient.mp3` | Soft station ambience — birds, distant wind | Yes | freesound.org "train station ambience" |
| `ambient.webm` | WebM fallback for `ambient.mp3` | Yes | — |
| `train_engine.mp3` | Steam / diesel engine rumble loop | Yes | freesound.org "steam locomotive idle" |
| `train_engine.webm` | WebM fallback | Yes | — |
| `rail_clicks.mp3` | Track clack rhythm — ties under wheels | Yes | freesound.org "train rail clicks" |
| `rail_clicks.webm` | WebM fallback | Yes | — |
| `horn.mp3` | Train whistle / horn — one shot | No | freesound.org "steam train horn" |
| `horn.webm` | WebM fallback | No | — |
| `brake.mp3` | Brake squeal — one shot | No | freesound.org "train brake squeal" |
| `brake.webm` | WebM fallback | No | — |
| `station_announcement.mp3` | Arrival announcement — one shot | No | freesound.org "train station announcement" |
| `station_announcement.webm` | WebM fallback | No | — |
| `door.mp3` | Door close clunk — one shot | No | freesound.org "train door close" |
| `door.webm` | WebM fallback | No | — |

## Recommended specs
- Format: MP3 (primary) + WebM (fallback)
- Sample rate: 44.1 kHz
- Bit rate: 128 kbps (loops) / 192 kbps (one-shots)
- Target volume normalisation: -18 LUFS
